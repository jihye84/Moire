# 무아레 정원

같은 무늬 두 장을 조금만 비틀어 겹치면, 어느 쪽에도 없던 커다란 무늬가 피어납니다.
무아레 현상을 손으로 만지며 감상하는 웹 갤러리입니다.

**주소:** https://jihye84.github.io/Moire/

## 기능

- **처음 화면**: 무지개빛 보기, 기울이기 움직임으로 시작합니다(기울기 센서가 없는 기기는 흐르기)
- **아래 메뉴**: 정보 · 무늬 · 조절 · 전체 · 숨기기
- **정보**: 왼쪽 위에 무늬 이름과 중요한 숫자(회전 각도, 배율, 중심 거리, 띠 간격 등)를 투명한 바탕에 작은 글자로 실시간 표시. 끄면 글자가 모두 사라집니다
- **무늬 서랍**: 무엇을 볼지 고르기
  - 무아레 종류 8가지: 바퀴살 꽃(첫 화면), 어긋난 과녁, 육각 초격자, 존 플레이트, 물결 필름, 점 격자, 비튼 줄무늬, 1% 확대
  - 보는 방식: 무지개 · 빛 · 흑백 / 두 장 · 아래만 · 위만
  - 움직임: 기울이기 · 흐르기 · 정지(위 필름이 처음 자리로 돌아감)
- **조절 서랍**: 위 필름의 회전 · 배율 · 간격 · 굵기 · 무늬별 세부 값. 슬라이더를 잡고 있는 동안에는 서랍이 투명해지고 그 슬라이더만 남아 무늬 전체를 보며 조절할 수 있습니다
- **기울이기**: 위 필름이 폰 위에 올려 둔 필름처럼 움직입니다. 기울인 쪽으로 미끄러졌다 출렁이며 멈추고, 좌우 기울기만큼 비틀리고, 앞뒤로 기울이면 살짝 들려 배율이 바뀝니다. 흔들면 흩어졌다가 제자리로 돌아옵니다. 아이폰은 처음 화면을 만질 때 기울기 사용 허락을 묻습니다
- **손으로**: 끌어서 위 필름 이동, 두 손가락으로 회전·확대, 마우스 휠로 회전(Shift+휠: 확대)
- **전체 화면**: 휴대폰에서 처음 화면을 만지면 주소창 없이 전체 화면으로 바뀝니다('전체' 버튼으로 켜고 끔). 브라우저 전체 화면에서는 휴대폰이 '전체 화면 종료 방법' 안내 띠를 잠깐 띄웁니다(웹 페이지가 끌 수 없는 브라우저 기능). 안내 띠 없이 보려면 앱으로 설치해 여세요. 안드로이드 크롬·삼성 인터넷에서는 아래 메뉴에 '설치' 버튼이 나타납니다. 직접 하려면 안드로이드는 브라우저 메뉴 → '홈 화면에 추가' 또는 '앱 설치', 아이폰은 Safari 공유 → '홈 화면에 추가'
- **숨기기**: 메뉴를 치우고 무늬(와 켜 둔 정보 글자)만 남깁니다. 화면을 짧게 톡 누르면 메뉴가 다시 나옵니다
- 주소 끝에 `#rings`, `#hex`처럼 무늬 이름을 붙이면 그 무늬로 바로 열립니다 (spokes, rings, hex, zone, wave, dots, lines, zoom)
- 카카오톡·페이스북·인스타그램·네이버 등 앱 안의 브라우저에서 열면 기본 브라우저로 다시 엽니다(아이폰은 안내 화면)
- 어떤 화면 크기에서도 스크롤 없이 보이도록 맞춰져 있습니다

## 기술

- `index.html` 한 파일, WebGL2 프래그먼트 셰이더로 모든 무늬를 픽셀마다 계산합니다
- 화면 픽셀보다 촘촘한 무늬는 평균 밝기로 흐리게 처리해, 화면 자체가 만드는 가짜 무아레가 섞이지 않게 했습니다
- 글꼴: Gowun Batang, IBM Plex Sans KR, IBM Plex Mono (Google Fonts, SIL Open Font License)
