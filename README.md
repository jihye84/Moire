# 무아레 정원

같은 무늬 두 장을 조금만 비틀어 겹치면, 어느 쪽에도 없던 커다란 무늬가 피어납니다.
무아레 현상을 손으로 만지며 감상하는 웹 갤러리입니다.

**주소:** https://jihye84.github.io/Moire/

## 기능

- **갤러리 8종**: 비튼 줄무늬, 어긋난 과녁, 바퀴살 꽃, 육각 초격자, 존 플레이트, 물결 필름, 점 격자, 1% 확대
- **조작**: 끌어서 위 필름 이동, 두 손가락으로 회전·확대, 마우스 휠로 회전(Shift+휠: 확대)
- **전체 화면**: 휴대폰에서 처음 화면을 만지면 주소창 없이 전체 화면으로 바뀝니다(아래 띠의 '전체' 버튼으로 켜고 끔). 아이폰은 Safari의 공유 → '홈 화면에 추가'로 열면 전체 화면 앱처럼 열립니다
- **메뉴 숨기기**: '숨기기'를 누르면 무늬만 남고, 화면을 짧게 톡 누르면 메뉴가 다시 나옵니다
- **폰 기울이기**: 조절 서랍의 '기울여 보기'를 켜면 위 필름이 폰 위에 올려 둔 필름처럼 움직입니다. 기울인 쪽으로 미끄러졌다 출렁이며 멈추고, 좌우 기울기만큼 비틀리고, 앞뒤로 기울이면 살짝 들려 배율이 바뀝니다. 흔들면 흩어졌다가 제자리로 돌아옵니다
- **보는 방식**: 필름(잉크와 종이) · 빛(두 빛줄기의 합) · 무지개(색마다 각도가 살짝 다른 필름)
- **한 장씩 보기**: 아래 필름만, 위 필름만 따로 볼 수 있습니다
- **띠 간격 계산**: D = d₁·d₂ / √(d₁² + d₂² − 2·d₁·d₂·cos θ)
- 주소 끝에 `#rings`, `#hex`처럼 프리셋 이름을 붙이면 그 무늬로 바로 열립니다
  (lines, rings, spokes, hex, zone, wave, dots, zoom)
- 카카오톡·페이스북·인스타그램·네이버 등 앱 안의 브라우저에서 열면 기본 브라우저로 다시 엽니다(아이폰은 안내 화면)

## 기술

- `index.html` 한 파일, WebGL2 프래그먼트 셰이더로 모든 무늬를 픽셀마다 계산합니다
- 화면 픽셀보다 촘촘한 무늬는 평균 밝기로 흐리게 처리해, 화면 자체가 만드는 가짜 무아레가 섞이지 않게 했습니다
- 글꼴: Gowun Batang, IBM Plex Sans KR, IBM Plex Mono (Google Fonts, SIL Open Font License)
